01 · GERÄT ERKENNEN

Der richtige Anschluss.

BOOT am ESP halten, USB-Datenkabel einstecken, BOOT lösen. Schließe andere Programme, die den Port verwenden.

USB-Zugriff erfolgt erst nach deiner Auswahl. Im Browser sind nur von dir freigegebene Geräte sichtbar.

Bei mehreren gleichen Einträgen den ESP abziehen, die Auswahl erneut öffnen und vergleichen. Für eine vollständige COM-Liste mit Seriennummern: lokalen Flash-Assistenten herunterladen.

02 · FIRMWARE INSTALLIEREN

Eine Verbindung. Ein Klick.

Wähle dasselbe USB-Gerät im Installationsdialog. Die Chip-Familie wird geprüft. Eine vollständige Löschung ist bei fremder Firmware sinnvoll und löscht auch WLAN sowie Messpuffer. Bei Updates die Löschoption bewusst deaktiviert lassen.

Dein Browser bietet kein Web Serial. Verwende Desktop-Chrome/Edge oder den lokalen Flash-Assistenten.

USB-Flashen benötigt HTTPS oder localhost. Öffne diese Seite über den GitHub-Pages-Link.

Version 0.2.0 · SHA-256 · Firmware herunterladen

03 · ZUHAUSE EINRICHTEN

Deine Daten bleiben bei dir.

  1. Nach dem Flash USB kurz trennen und ohne BOOT neu verbinden.
  2. WLAN Gas-Setup-<Suffix> wählen, Passwort gas-<Suffix>.
  3. Den allgemeinen Setup-Zugang 192.168.4.1 öffnen. Eigene WLAN-/Serverdaten und das Sensor-Passwort aus dem Dashboard eintragen.
  4. Im Dashboard den Impulswert speichern und den physischen Zählerstand abgleichen.

Linux-Server und Sensor Schritt für Schritt einrichten ↗

Die USB-Verbindung liegt zwischen deinem PC-Browser und dem ESP. Ein GitHub-Server greift nicht auf deine COM-Ports zu. GitHub Pages hostet die Firmware, ESP Web Tools wird versionsgebunden von unpkg geladen.

Hardwareprüfung am realen ESP bleibt erforderlich. Während der ESP stromlos ist, werden keine Pulse erfasst.
